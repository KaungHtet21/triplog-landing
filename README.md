# Triplog Landing

Premium marketing site for **Triplog** — a social travel companion for friends.

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- Framer Motion
- GSAP (ScrollTrigger)

## Structure (Atomic)

```
src/
  components/
    atoms/
    molecules/
    organisms/
  pages/
  hooks/
  lib/
```

## Run

```bash
yarn
yarn dev
```
